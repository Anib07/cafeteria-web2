# cafeteria-web2

Proyecto web responsivo de una cafetería moderna con animaciones interactivas, menú digital y sucursales con mapas integrados.
Este proyecto es una página web completa para una cafetería moderna, diseñada con HTML, CSS y JavaScript. Incluye:

Hero interactivo: Animaciones de café flotante y efecto de movimiento según la posición del mouse.

Menú responsive: Secciones de productos con botones estilizados y menú hamburguesa funcional en móviles.

Sección de sucursales: Cards con mapas integrados, botones de dirección y llamada.

Formulario de contacto: Diseño con efecto vidrio, validación básica y enlaces a redes sociales.

Animaciones y efectos visuales: Smooth scroll, hover effects, degradados, y animaciones flotantes.

Responsive design: Totalmente adaptable a móviles y tablets.

Este proyecto demuestra habilidades en frontend, diseño responsivo y animaciones interactivas, ideal para mostrar en portafolio personal.
